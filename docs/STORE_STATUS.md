# Decky store status

Ayaneo3 Fans is distributed manually through signed/versioned GitHub release
assets and Decky's URL/ZIP installer.

It is not being submitted to the official Decky store in this release cycle. The
current store checklist requires that generative AI did not write a majority of
the submitted code and requires third-party SteamOS testing. This project includes
Codex-assisted code and depends on a separately installed Bazzite system service.

Do not submit a checklist or imply approval while those conditions remain unmet.
